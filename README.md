# Python Pong Game !

A simple Pong-style arcade game built with Python using the `play` library.

Control a paddle with the mouse to keep the ball in play and earn points by bouncing it off the paddle.

## Features

- **Player-Controlled Paddle:** Move the paddle horizontally to catch the ball.
- **Ball Physics:** The ball bounces off the court boundaries and paddle.
- **Scoring System:** Earn points when the ball hits the paddle; lose points when it falls past the bottom.
- **Dynamic Difficulty:** The paddle shrinks as your score increases, and the ball speeds up at higher scores.
- **Custom Visual Design:** Features a pink court, colorful game elements, and decorative smiley faces.

## Technologies

- Python
- `play` library
- Pygame
- Randomized angles for ball movement

## How to Play

1. Run the program in an environment that supports the `play` library.
2. Move your mouse horizontally to control the paddle.
3. Bounce the ball off the paddle to earn points.
4. Avoid letting the ball fall past the bottom of the court!
